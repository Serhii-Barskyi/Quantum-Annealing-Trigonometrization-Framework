# Retained case300 hardware evidence

This document records the **preserved historical real-D-Wave case300 evidence** discussed in *Quantum Annealing Trigonometrization*. It is not regenerated by the scalable GPU/SQA notebook and must not be transferred to the `K=80, B=15` simulator protocol.

## Fixed protocol

- IEEE 300-bus `case300`
- 1600 training scenarios / 400 held-out REI scenarios
- complex feature count: 818
- train-only shortlist: `K=27`
- BESS budgets: `B=2` and `B=3`
- real D-Wave hardware response
- independent nonlinear AC/OOD/N-1 evaluation

The retained `B=3` QPU portfolio placement `[236, 57, 90]` differs from the brute-force fixed-QUBO optimum `[236, 57, 281]`; downstream nonlinear AC validation gave the former greater physical value on the evaluated scenario. This motivates portfolio-based evaluation but is not a universal superiority theorem.

## Claim boundary

These results establish a positive physical margin for the fixed retained case300 protocol. They do **not** establish universal quantum speedup, universal superiority over classical optimization, cross-network generalization, or cross-hardware reproducibility.


## Public execution-adaptation boundary

The repository's `notebooks/CSSF_dwave_case300.ipynb` is a **security/path-normalized public execution adaptation** of the preserved notebook. The original external historical support modules used by the saved run are not present among the supplied source artifacts, so `case300_compat/` reconstructs the narrow runtime API needed for public execution. It is tested for frozen dataset loading, toric checks, candidate ordering, QUBO feasibility, QUBO↔Ising identity, and fail-closed System4/System6 routing, but it is **not claimed to be byte-identical to the missing historical support package**.

The preserved `rho_OOD = 0.9914438669` remains a historical result under the original external metric implementation. With the explicitly published flattened non-slack Pearson definition in the compatibility layer, a CPU regeneration gives approximately `rho_global = 0.99053`. The difference is retained as a public reproducibility boundary rather than hidden or used to overwrite the historical record. A new live-QPU execution is a new hardware observation.

The same non-identity is visible in the reconstructed QUBO penalty scale: the compatibility layer currently derives a conservative `lam_pen ≈ 81.4358`, while the preserved historical notebook output recorded approximately `1079.86`. The reconstructed QUBO passes exact-cardinality checks, reproduces the CPU brute-force optima `[236,57]` for `B=2` and `[236,57,281]` for `B=3`, and passes the QUBO↔Ising energy identity to below `1e-8`; nevertheless, the penalty-scale difference means the release does **not** claim exact numerical reconstruction of the missing historical QUBO builder.
